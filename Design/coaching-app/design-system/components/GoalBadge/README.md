# GoalBadge

GoalBadge shows an Exercise's Training Goal: Force, Hypertrophie or Endurance.

## When to use
Next to an Exercise name in cards, lists and the Program editor; in chart legends. The same movement can carry different goals in different Programs, so always show the badge where the goal drives the recommendation.

## The consumer provides
`goal` (`strength` | `hypertrophy` | `endurance`), optional `size="sm"`.

## Don't
Show the goal color without its label: in dark, Force and Hypertrophie sit at similar lightness.
